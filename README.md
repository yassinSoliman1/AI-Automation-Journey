## Planned project documentation

Each project should include:

1. **Problem:** What manual task or business challenge does it address?
2. **Solution:** How the automation works, including a workflow diagram.
3. **Stack:** Actual tools, APIs, and services used.
4. **Setup:** Prerequisites, environment variables, and run instructions.
5. **Demo:** Screenshots, sample inputs/outputs, or a short video.
6. **Reliability:** Error handling, logging, and limitations.

## Security

Never commit API keys, access tokens, customer data, or `.env` files. Provide a sanitized `.env.example` when a project needs configuration.
